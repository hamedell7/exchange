# Service Boundaries

## Identity

مالک: حساب کاربری، اطلاعات ورود، اعتبارنامه‌ها، نشست‌ها و مجوزهای هویتی.

## Wallet

مالک: حساب‌های دارایی، دفتر کل، ثبت بدهکار/بستانکار، رزروها و مانده‌های محاسبه‌شده از دفتر کل.

## Trading

مالک: بازارها، سفارش‌ها و معاملات. Trading برای رزرو یا آزادسازی وجه از قرارداد Wallet استفاده می‌کند و نباید مستقیماً جداول آن را بخواند.

## Gateway

مسئول ورود و مسیریابی درخواست‌هاست؛ مالک منطق دامنه نیست.

## اصل استقلال

هر سرویس دیتابیس، Migration، استقرار و چرخه انتشار مستقل دارد. هیچ Foreign Key بین دیتابیس‌های سرویس‌ها وجود نخواهد داشت.
