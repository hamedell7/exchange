# API Gateway

این Repository فقط مسئول لایه ورودی و مسیریابی است.

## مسئولیت‌ها

- TLS termination در محیط استقرار مناسب
- Routing و محدودیت اندازه درخواست
- Rate limiting در سطح لبه
- افزودن و انتقال Correlation ID
- Health/readiness routing در صورت نیاز
- مدیریت پاسخ خطاهای Gateway و timeoutها

## خارج از مسئولیت

- منطق تجاری، سفارش‌گذاری یا محاسبه موجودی
- مالکیت کاربران یا مجوزهای دامنه‌ای
- دسترسی مستقیم به دیتابیس سرویس‌ها

اعتبارسنجی اولیه توکن در Gateway جایگزین بررسی مجوز توسط سرویس مقصد نیست.

فعلاً پیکربندی Nginx عمداً اضافه نشده؛ مسیرها و سیاست‌ها بعد از مشخص شدن قرارداد API سرویس‌ها تعریف می‌شوند.
