# Exchange Contracts

این Repository فقط قراردادهای عمومی بین سرویس‌ها را نگهداری می‌کند؛ نه کد داخلی سرویس‌ها را.

## ساختار

- `openapi/identity`: قراردادهای REST مربوط به Identity
- `openapi/wallet`: قراردادهای REST مربوط به Wallet
- `openapi/trading`: قراردادهای REST مربوط به Trading
- `events/`: Schema پیام‌ها و Eventهای RabbitMQ

## قواعد

1. قراردادها قبل از تغییر ناسازگار نسخه‌بندی می‌شوند.
2. هیچ Secret، داده شخصی واقعی یا نمونه اطلاعات حساس در این Repository قرار نمی‌گیرد.
3. Eventها دارای نام، نسخه، شناسه پیام، زمان وقوع و Correlation ID خواهند بود.
4. مصرف‌کننده Event باید با دریافت تکراری پیام سازگار باشد (idempotent).
5. تغییرات ناسازگار API یا Event نیازمند برنامه مهاجرت و بازه سازگاری است.

قراردادها در این مرحله عمدی خالی هستند تا قبل از طراحی Use Caseها API خیالی تعریف نکنیم.
